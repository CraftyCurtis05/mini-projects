JavaScript Beginner–Intermediate

Variables & Data Types

Core JavaScript values and declarations used to store and work with data.

Core JavaScript values and declarations used to store and work with data.
Term / Syntax Name Description Example
let Block-scoped variable Declares a variable whose value can be reassigned. let count = 1;
const Block-scoped constant Declares a binding that cannot be reassigned. const siteName = "Web Dev Reference";
string Text value Represents textual data. const name = "Jennifer";
number Numeric value Represents integer and floating-point numbers. const score = 98.5;
boolean True/false value Represents one of two logical states. const isVisible = true;
null Intentional empty value Represents the intentional absence of a value. const selectedItem = null;
undefined Missing value Commonly represents a declared value that has not been assigned. let result;
typeof Type operator Returns a string describing a value's JavaScript type. typeof 42; // "number"

Operators & Control Flow

Expressions and statements used to compare values, make decisions, and repeat work.

Expressions and statements used to compare values, make decisions, and repeat work.
Term / Syntax Name Description Example
=== Strict equality Compares value and type without coercion. status === "ready"
!== Strict inequality Returns true when value or type differs. count !== 0
&& Logical AND Returns truthy only when both operands are truthy. isLoggedIn && isAdmin
|| Logical OR Returns the first truthy operand. displayName || "Guest"
?? Nullish coalescing Uses a fallback only when the left value is null or undefined. username ?? "Guest"
if / else Conditional statement Runs different blocks based on a condition. if (score >= 70) { pass(); } else { retry(); }
switch Multi-branch conditional Matches one expression against multiple cases. switch (theme) { case "dark": applyDark(); break; }
for...of Iterable loop Loops through iterable values such as arrays. for (const item of items) { console.log(item); }

Functions

Reusable blocks of behavior for organizing logic and transforming values.

Reusable blocks of behavior for organizing logic and transforming values.
Term / Syntax Name Description Example
function Function declaration Creates a named reusable function. function greet(name) { return `Hi ${name}`; }
=> Arrow function Provides concise function syntax and lexical this behavior. const double = value => value * 2;
return Return value Ends a function and sends a value back to the caller. return total;
default parameter Fallback argument Provides a value when an argument is omitted or undefined. function greet(name = "Guest") { }
rest parameter Collect arguments Collects remaining arguments into an array. function sum(...numbers) { }
callback Function argument Passes a function to another function for later use. items.forEach(item => console.log(item));

Arrays & Objects

Common structures for collections, records, transformation, and lookup.

Common structures for collections, records, transformation, and lookup.
Term / Syntax Name Description Example
[] Array Stores an ordered collection of values. const skills = ["HTML", "CSS", "JavaScript"];
{} Object Stores key/value properties. const user = { name: "Jennifer", role: "Developer" };
.map() Array mapping Creates a new array by transforming each item. const names = users.map(user => user.name);
.filter() Array filtering Creates a new array containing matching items. const active = users.filter(user => user.active);
.find() Find item Returns the first array item matching a condition. const admin = users.find(user => user.role === "admin");
.reduce() Reduce collection Combines array values into one accumulated result. const total = prices.reduce((sum, price) => sum + price, 0);
destructuring Extract values Pulls properties or items into variables. const { name, role } = user;
spread Copy/merge syntax Expands iterable items or object properties. const updated = { ...user, active: true };

Modern JavaScript

Language features commonly used in modern front-end projects.

Language features commonly used in modern front-end projects.
Term / Syntax Name Description Example
template literal Interpolated string Creates strings with embedded expressions. const message = `Hello, ${name}!`;
?. Optional chaining Safely accesses nested properties that may be missing. user.profile?.avatar
export Module export Makes values available to another module. export function formatDate(date) { }
import Module import Loads exported values from another module. import { formatDate } from "./utils.js";
try / catch Error handling Handles errors thrown during an operation. try { parseData(); } catch (error) { console.error(error); }
throw Throw error Creates or rethrows an error condition. throw new Error("Invalid value");
