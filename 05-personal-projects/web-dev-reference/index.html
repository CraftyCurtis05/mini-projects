Web Development Reference

The web development notes and references I keep coming back to.

Welcome

I started this as an HTML tables cheat sheet because I kept looking up the same things. I kept adding pages as I learned more and found other topics I wanted to keep in one place.

I use it as a quick place to check syntax, examples, and reminders while I am working on other projects.

How to use this reference

  • ⌕ Search: Find a term on a page or across the entire reference.
  • </> Code: Examples use a dedicated monospace style for fast scanning.
  • ▤ Reference: Tables provide concise definitions and examples.
  • ◇ Patterns: Complete examples show concepts working together.
  • ★ Jennifer's Note: Things I learned while building and debugging.
