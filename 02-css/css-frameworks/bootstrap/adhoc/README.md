# Adhoc

A Bootstrap practice project where I worked with the framework's grid and utility classes instead of writing every layout rule from scratch.

This is one of my Codecademy practice projects, so I keep it small and focused on the concept I was learning at the time.

## What I Practiced

- Bootstrap layout classes
- the grid system
- responsive utilities
- combining framework styles with page content

## Built With

- HTML
- Bootstrap

## Project Structure

```text
├── assets/
└── index.html
```

## Running the Project

Open `index.html` in a browser.
