# Color Generator

A DOM events project that changes page colors in response to user interaction.

This is one of my Codecademy practice projects, so I keep it small and focused on the concept I was learning at the time.

## What I Practiced

- click and wheel event listeners
- DOM selection
- `event.currentTarget`
- updating styles with JavaScript
- small reusable functions

## Built With

- HTML
- CSS
- JavaScript

## Project Structure

```text
├── test/
├── index.html
├── main.js
└── style.css
```

## Button Behavior

`Pick a Color` changes color when it is clicked.

The original Codecademy step for `Mystery Color` practiced the `wheel` event, so scrolling over that button still changes its color. I also added a normal click listener because a visible button should still work when I click it.

## Running the Project

Open `index.html` in a browser.
