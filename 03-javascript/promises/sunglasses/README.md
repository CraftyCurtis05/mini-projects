# Sunglasses Promises

A JavaScript promises exercise I used to practice handling work that finishes later and reacting to success or failure.

This is one of my Codecademy practice projects, so I keep it small and focused on the concept I was learning at the time.

## What I Practiced

- Promises
- `.then()` and `.catch()`
- asynchronous flow
- handling resolved and rejected results

## Built With

- JavaScript

## Project Structure

```text
├── test/
├── app.js
└── library.js
```

## Small UI I Added

I added a Check Order button so I can watch the `Promise.all()` exercise succeed or fail in the browser. The same availability helper still works from Node.js.

I kept the interface small on purpose so the original concept is still the part I am practicing.

## UI Theme

The orange and gold colors make this feel more like a sunny retail/order check, which fits the sunglasses example.

## Running the Project

Run `app.js` with Node.js.

## Notes

I keep this project in my learning repository so I can look back at the code and see how I approached the concept when I first practiced it. I try to leave the code readable instead of making a small course exercise more complicated than it needs to be.

Some library or helper files were provided with the exercise. I left those separate from the code I was practicing.
