# Handlebars Hello

A small Handlebars exercise where I practiced compiling a template and adding the result to the page.

This is one of my Codecademy practice projects, so I keep it small and focused on the concept I was learning at the time.

## What I Practiced

- Handlebars templates
- template compilation
- passing data into a template
- rendering generated HTML

## Built With

- HTML
- CSS
- JavaScript
- Handlebars

## Project Structure

```text
├── public/
├── test/
├── handlebars.min.js  # library file
└── index.html
```

## Running the Project

Open `index.html` in a browser.

## Notes

I keep this project in my learning repository so I can look back at the code and see how I approached the concept when I first practiced it. I try to leave the code readable instead of making a small course exercise more complicated than it needs to be.

Some library or helper files were provided with the exercise. I left those separate from the code I was practicing.
