# School Classes

A JavaScript class exercise where I modeled schools and shared behavior with inheritance.

This is one of my Codecademy practice projects, so I keep it small and focused on the concept I was learning at the time.

## What I Practiced

- classes and constructors
- inheritance
- instance methods
- organizing related data and behavior

## Built With

- JavaScript

## Project Structure

```text
└── app.js
```

## Small UI I Added

I added a small school catalog interface so I can create instances of the different school subclasses and see the inherited data on the page.

I kept the interface small on purpose so the original concept is still the part I am practicing.

## UI Theme

I kept this one clean and classroom-like with blue, white, and a small yellow accent.

## Running the Project

Run `app.js` with Node.js.

## Notes

I keep this project in my learning repository so I can look back at the code and see how I approached the concept when I first practiced it. I try to leave the code readable instead of making a small course exercise more complicated than it needs to be.
