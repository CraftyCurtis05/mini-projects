# Library Classes

A JavaScript class exercise where I modeled a library and different types of media with objects and inheritance.

This is one of my Codecademy practice projects, so I keep it small and focused on the concept I was learning at the time.

## What I Practiced

- JavaScript classes
- constructors
- inheritance
- methods and object state

## Built With

- JavaScript

## Project Structure

```text
└── app.js
```

## Small UI I Added

The original class exercise was console-based. I added `index.html` and `style.css`, then connected the existing class idea to a catalog where I can add media, toggle checkout status, and add a rating.

I kept the interface small on purpose so the original concept is still the part I am practicing.

## UI Theme

I used warm paper and book-cover colors here because it makes the catalog feel like a small library instead of another generic form.

## Running the Project

Run `app.js` with Node.js.
