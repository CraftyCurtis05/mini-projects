Web Development Reference

A quick-reference library for HTML and CSS fundamentals.

Welcome

I started this reference as a place to keep the web-development concepts I found myself looking up repeatedly. As I kept building, it grew into a broader collection of syntax, patterns, accessibility practices, debugging reminders, and the small lessons that are easy to forget between projects.

Built for learning, remembering, and building — with accessibility, reusable patterns, and clear examples treated as part of the design rather than add-ons.

How to use this reference

  • ⌕ Search — Find a term on a page or across the entire reference.
  • </> Code — Examples use a dedicated monospace style for fast scanning.
  • ▤ Reference — Tables provide concise definitions and examples.
  • ◇ Patterns — Complete examples show concepts working together.
  • ★ Jennifer's Note — Practical observations from building and learning.
